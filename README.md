# DE Pro Drill

Offline practice app for the Databricks Data Engineer Professional exam (Oct 2026 outline).
Every question is written from a docs.databricks.com page and links back to it. Not affiliated with Databricks.

Open https://joeyfaherty.github.io/databricks-de-pro-app/ in Chrome on Android, then choose ⋮ → Add to Home screen.
Generated from a private study repo; edits here are overwritten.
